# Base de Datos - PostgreSQL (Puntos 26-59)

## Descripción
Proyecto completo de base de datos para una plataforma de música (tipo Spotify) con ejercicios de PostgreSQL.

## Tablas principales

- **usuarios** - Información de usuarios
- **plan** - Tipos de suscripción
- **artistas** - Cantantes y bandas
- **albumes** - Colecciones de canciones
- **canciones** - Temas individuales
- **suscripciones** - Relación usuario-plan
- **playlist** - Listas personalizadas
- **reproducciones** - Historial de escuchas
- **me_gusta** - Favoritos
- **seguir_artista** - Seguir artistas
- **seguir_usuario** - Seguir usuarios

## Puntos cubiertos

### Punto 26: IS NULL - IS NOT NULL
Ver usuarios sin edad o sin teléfono

### Punto 30: DISTINCT
Ver países diferentes de artistas

### Punto 34: COUNT
Contar canciones totales

### Punto 35: SUM
Suma de precios de planes

### Punto 37: PRIMARY KEY
Ver restricciones de una tabla

### Punto 43: JOIN
Ver canciones con su álbum y artista

### Punto 38: GROUP BY
Contar suscripciones por plan

### Punto 39: HAVING
Planes con 2 o menos suscripciones
